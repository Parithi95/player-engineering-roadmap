End-to-end Player Engineering learning repository with theory, coding exercises, browser APIs, streaming protocols, and real-world implementations.

# Player Engineering Roadmap

## Goal

Become a Player Engineer by learning the complete streaming pipeline—from how a video is captured to how it is played on browsers, TVs, and mobile devices.
